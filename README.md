# his-tag-kg 本地一键启动操作指南

> **适用系统**：macOS / Windows | **前置要求**：已安装 Python 3.10 或更高版本（[python.org](https://www.python.org/)）

---

## 一、解压项目压缩包（通用准备）

1. 将收到的 `his-tag-kg.zip` 压缩包保存到本地（建议放在桌面或纯英文目录中，例如 `Desktop/his-tag-kg`）。
2. 双击或右键解压生成 `his-tag-kg` 文件夹。
3. **路径注意**：请确保文件夹所在路径不包含中文字符或特殊空格，以免脚本运行异常。

---

## 二、macOS 操作环境一键启动步骤（`start_mac.sh`）

1. **打开终端（Terminal）**：按快捷键 `Command + 空格` 打开聚焦搜索，输入 `Terminal` 并按回车键。
2. **进入解压后的项目文件夹**：假设文件夹解压在桌面，输入以下命令并回车（若在其他位置，可先输入 `cd ` 加空格后将文件夹拖入终端回车）：

```bash
cd ~/Desktop/his-tag-kg
```

3. **赋予脚本执行权限并一键启动**：依次输入并执行以下命令：

```bash
chmod +x start_mac.sh
./start_mac.sh
```

4. **验证启动成功**：首次运行会自动创建 `.venv` 虚拟环境、安装依赖并初始化本地示例数据库（约需 1~2 分钟）。当终端输出 `Uvicorn running on http://127.0.0.1:8000` 时，默认浏览器会自动弹出应用网页。
5. **停止运行**：保持终端窗口开启即可持续使用；如需关闭服务，在终端窗口中按 `Ctrl + C`。

---

## 三、Windows 操作环境一键启动步骤（`start_windows.bat`）

1. **确认 Python 环境变量**：安装 Python 3.10+ 时，请务必在安装界面底部勾选 **“Add python.exe to PATH”**；若此前未勾选，建议重新运行安装程序修复并勾选该项。
2. **直接双击启动脚本**：打开解压后的 `his-tag-kg` 文件夹，找到 `start_windows.bat` 文件，直接鼠标双击运行，系统将自动弹出命令行窗口并开始初始化。
3. **备用命令行启动方式（若双击窗口一闪而过）**：在 `his-tag-kg` 文件夹顶部地址栏点击一下，输入 `cmd` 回车打开命令提示符，然后执行：

```cmd
start_windows.bat
```

4. **验证启动成功**：首次启动会自动建立虚拟环境、下载依赖并配置本地 SQLite 示例数据库（请保持网络畅通，等待约 1~2 分钟）。看到 `Uvicorn running on http://127.0.0.1:8000` 提示后，默认浏览器会自动打开应用界面。
5. **停止运行**：保持命令行窗口开启即可正常使用；使用完毕后直接关闭该窗口，或在窗口中按 `Ctrl + C`。

---

## 四、常见问题与快速排查

| 现象 | 原因与解决方法 |
| :--- | :--- |
| 提示找不到 `python` / `python3` | 未安装 Python 3.10+ 或未加入系统 PATH。安装完成后请**重新打开终端/命令行窗口**再运行启动脚本。 |
| 浏览器弹出后显示“无法访问此网站” | 浏览器弹出速度略快于后端加载速度，等待 2~3 秒后在浏览器中**刷新页面**即可；也可手动访问 `http://127.0.0.1:8000`。 |
| 提示 `8000` 端口被占用 | 本机已有其他程序占用了 8000 端口。可关闭冲突程序，或用文本编辑器打开对应启动脚本，将 `--port 8000` 修改为 `--port 8001` 后重新运行。 |
| macOS 提示 `Permission denied` | 未授予脚本可执行权限，在终端先执行 `chmod +x start_mac.sh` 后再运行 `./start_mac.sh`。 |
